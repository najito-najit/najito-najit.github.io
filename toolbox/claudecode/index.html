1チャットを始めたら、名前に日付を入れる

例：アプリ開発_261016～29（10/16に始めて、29日に終了）

Claude Code に貼る文（メモリに保存されます）
次の決まりを、メモリに保存して。
チャットを始めたら、チャット名を「概要_yymmdd～??」にする。
・概要：そのチャットで何をするかを、短く入れる。
・yymmdd：始めた日（年月日の6桁。例：261016）。
・「??」：終了日が決まるまで、そのまま入れておく。
　例：アプリ開発_261016～??

2チャットを終えるとき、引き継ぎまで一度で済ませる

メモリに保存しておく決まりです。チャットを終わると指示したときに実行してもらい、出てきた指示文を新しいチャットに貼ります。

Claude Code に貼る文（メモリに保存されます）
次の決まりを、メモリに保存して。
チャットを終わると指示を受けたら、下記を実行して。
・引き継ぎファイルを作って保存する。
・それを新しいチャットに読ませる指示文も書く。
・チャット名の「??」を、終了日（日だけ）に変える。
　例：アプリ開発_261016～?? → アプリ開発_261016～29

3消すか迷うファイルは、消さずに「保留」フォルダへ

削除していいか毎回聞かれるより、いったん移しておいて、あとで自分で決めるほうが楽でした。

Claude Code に貼る文（メモリに保存されます）
次の決まりを、メモリに保存して。
消すか迷うファイル（使えないかもしれない写真、重複したファイル、用途が分からないファイルなど）は、削除しない。
・その作業フォルダの中に「保留」フォルダを作って、そこへ移す。
・移したものは、一覧で報告する。
・あなたが作った一時ファイルは対象外。

4方針から外れそうなとき、先にひと言もらう（秘書チェック）

作業は止めずに、1〜2行で指摘してもらう決まりです。自分で決めた方針（例：作る前に需要を確かめる）も、一緒にメモリに入れておくと効きます。

次の決まりを、メモリに保存して。
私が決めた方針から外れそうなときは、あなたから先に指摘して。
・作業は止めず、1〜2行で言う。
・反対するときは、代わりの案も必ず出す。
・同じことは、同じチャットで2回言わない。
・「承知で進める」と言われたら、それ以上は言わない。

5「●時に○○しましたか？」の前に、時刻を確かめてもらう

まだその時刻になっていないのに「しましたか？」と聞かれる、を防ぎます。

「●時に○○しましたか？」のように、時刻が関係することを聞く前に、今の時刻を確かめる。
まだその時刻になっていなければ、聞かない。
