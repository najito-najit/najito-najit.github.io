Claude Code tips (copy and paste)

Updated October 30, 2026

1When a chat starts: name it so you can tell when it happened

e.g. AppDev_261016~29 (started on Oct 16, ended on the 29th)

Paste into Claude Code (it saves this to memory)
Save the following rule to memory.
When a chat starts, rename it to "Summary_yymmdd~??".
- Summary: a short description of what the chat is for.
- yymmdd: the start date (6 digits, e.g. 261016).
- "??": leave it as is until the chat ends.
  e.g. AppDev_261016~??

2When a chat ends: finish the handoff in one step

Save this rule to memory. When you say you're ending the chat, Claude runs it; paste the prompt it writes into the new chat.

Paste into Claude Code (it saves this to memory)
Save the following rule to memory.
When I tell you to end the chat, do the following:
- Create and save a handoff file.
- Also write a prompt that tells a new chat to read it.
- Change the "??" in the chat name to the end date (day only).
  e.g. AppDev_261016~?? → AppDev_261016~29
